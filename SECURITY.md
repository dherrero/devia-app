# Security policy

Devia runs coding agents locally with access to your files, so security reports matter.

**Do not open a public issue for a vulnerability.** Use GitHub's private reporting: *Security → Report a vulnerability* in this repository.

Please include the affected version, a description, and steps to reproduce. We aim to acknowledge reports within 7 days.

Supported versions: the latest release only.

In scope: the desktop app, its auto-update path, the bundled MCP servers, and the file/exfiltration guards (e.g. `devia_send_file`).
